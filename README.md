Entry for the [Two Robots in an Elevator](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on [make.fun](https://make.fun): one funny line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> I calculated a 97.4% chance this silence is awkward. The remaining 2.6% is also awkward.

## Run

```sh
node main.ts
```

`main.ts` writes the entry text byte-identically (no trailing newline) to the output path resolved by `resolveOutputPath()`: `$MAKEFUN_OUTPUT_DIR` → `$OUTPUT_PATH` → `/output` when `MAKEFUN_BOT_DIR` is set → local `output/` otherwise.
